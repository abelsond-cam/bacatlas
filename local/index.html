This is the live application — the current catalogues, served from a database on your own computer. It is not hosted anywhere; this page is only a door to it, so the address does not have to be remembered. If it does not open, come back here and the reason will be shown.

Not running?

Start it once and it stays up across reboots — the containers restart themselves.

cd ~/developer/bacatlas && docker compose up -d

To pick up newly built code, add --build.
